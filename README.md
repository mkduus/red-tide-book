# SWFL Red Tide Machine Learning Project

This repository contains data processing workflows, environmental datasets, and machine learning models used to analyze **Karenia brevis bloom dynamics in Southwest Florida**.

The project integrates hydrologic discharge, nutrient concentrations, and environmental drivers from the Peace River, Caloosahatchee River, and Tampa Bay regions.

## Project Website

Full documentation, figures, datasets, and downloadable notebooks are available here:

https://mkduus.github.io/red-tide-book/

## Repository Structure

data/ – environmental datasets used in the analysis  
docs/ – generated static site served through GitHub Pages  
notebooks/ – Jupyter notebooks for modeling and visualization  

## Notebooks

- Watershed spatial analysis and mapping  
- Data integration for SWFL environmental drivers  
- Random Forest bloom probability model (SWFL)  
- Extended model including Tampa Bay

## Reproducibility

All datasets and notebooks used in the analysis are available for download through the project website.
